# 摩旅与旅游智能路书系统设计文档

## 1. 项目背景

本系统面向摩旅、自驾游和普通旅游用户，提供基于地图的路书创建、点位编排、路线规划、AI 旅游推荐、短链分享、邀请协作、手机端出行打卡和高德地图导航唤醒能力。

系统只开发浏览器版本，包括 PC Web 端和手机 H5 端，不开发原生 App。PC Web 端主要用于创建和编辑路书，手机 H5
端主要用于出行时查看路书、开始旅游、分段导航和到点打卡。

系统技术栈基于若依 SpringBoot3 前后端分离版，后端使用 Spring Boot 3、JDK17+、MySQL、MyBatis-Plus。Spring Boot 3.0 官方要求
Java 17 作为最低版本，因此项目建议统一使用 JDK17 或 JDK21。

## 2. 项目目标

系统目标是提供一套完整的旅游路书工具，核心能力包括：

1. 用户可以在高德地图上搜索地点，并将地点加入路书。
2. 用户可以配置起点、终点、途经点、住宿点、美食点、补给点等。
3. 用户可以根据偏好获取 Tavily 搜索出来的旅游推荐内容。
4. 用户可以将推荐内容一键加入路书。
5. 用户可以生成路书短链分享给他人查看。
6. 用户可以生成邀请链接，让他人注册后加入路书协作。
7. 用户手机打开 H5 页面后，可以点击“开始旅游”。
8. 系统根据用户当前定位匹配路书进度。
9. 用户点击“开始导航”后，系统唤醒高德地图 App 导航到当前目标点。
10. 用户到达每个点位后可以进行打卡，避免系统误判已经到过或未到过的地方。
11. 后台可以配置高德地图 Key、Tavily API Key、AI 模型、偏好标签、搜索站点、搜索模板和审计日志。

## 3. 功能边界

### 3.1 本期支持

本期支持：

1. Web/H5 浏览器访问。
2. 高德地图展示。
3. 用户当前位置定位。
4. POI 搜索。
5. 路书点位添加、删除、排序、编辑。
6. 路线分段规划。
7. Tavily 搜索旅游推荐。
8. AI 摘要和推荐理由生成。
9. 路书短链分享。
10. 邀请注册和协作权限。
11. 手机端开始旅游。
12. 手机端点位打卡。
13. 手机端唤醒高德地图导航。
14. 后台配置和审计日志。

### 3.2 本期不做

本期不做：

1. 不开发原生 Android / iOS App。
2. 不开发小程序。
3. 不接向量数据库。
4. 不自建旅游攻略向量库。
5. 不直接爬取小红书、微博、贴吧等平台内容。
6. 不承诺把完整路书同步到高德账号。
7. 不承诺把多途经点完整写入高德 App 路书。

### 3.3 高德导航能力说明

系统使用高德 URI API 唤醒高德地图 App。高德 URI API 的路径规划服务地址为 `https://uri.amap.com/navigation`，适用于移动端和
PC 端，可用于路径规划跳转。

本系统采用“分段导航”方案，即一次只导航到当前目标点。用户到达并打卡后，再进入下一段导航。这样更适合摩旅和自驾游场景，也避免多途经点唤醒能力受限的问题。

## 4. 总体架构

系统采用单体后端 + 前后端分离架构。

```text
用户浏览器
  ├── PC Web 大屏地图工作台
  ├── 手机 H5 出行页
  └── 后台管理页

前端 Vue3 / 若依前端
  ├── 高德 JS API
  ├── 路书编辑组件
  ├── 出行打卡组件
  ├── Tavily 推荐展示组件
  └── 分享页 / 邀请页

后端 Spring Boot 3 / 若依
  ├── 用户认证与权限
  ├── 路书服务
  ├── 点位服务
  ├── 地图服务
  ├── 出行服务
  ├── 打卡服务
  ├── Tavily 推荐服务
  ├── AI 摘要服务
  ├── 分享短链服务
  ├── 邀请协作服务
  ├── 配置管理服务
  └── 审计日志服务

基础设施
  ├── MySQL
  ├── Redis
  ├── MinIO
  └── Nginx / HTTPS

第三方服务
  ├── 高德地图 JS API
  ├── 高德 Web 服务 API
  ├── 高德 URI API
  ├── Tavily Search API
  └── AI 模型 API
```


高德 JS API 2.0 是前端地图展示和交互的主要能力来源；定位可以使用浏览器定位能力或高德 JS API 的定位插件。高德 JS API
官方文档提供地图、插件和服务能力说明。

### 5.3 第三方 API

```text

- 地图展示
- 用户定位
- POI 搜索
- 路线规划
- URI 唤醒高德 App

Tavily：
- 旅游攻略搜索
- 站点限定搜索
- 结果相关性评分
- 可选 URL 内容抽取

AI 模型：
- 搜索关键词生成
- 推荐内容摘要
- 推荐理由生成
- 风险提醒生成
```

Tavily Search API 支持 `search_depth`、`max_results`、`include_domains`、`exclude_domains` 等参数，适合根据后台配置限定搜索网站并返回相关内容。

## 6. 核心业务流程

### 6.1 路书创建流程

```text
用户进入大屏地图
    ↓
系统获取用户当前位置
    ↓
地图中心点定位到用户当前位置
    ↓
用户搜索地点
    ↓
选择 POI 或地图点位
    ↓
添加到路书
    ↓
配置点位类型、停留时间、备注
    ↓
拖拽调整点位顺序
    ↓
系统重新计算分段路线
    ↓
保存路书
```

### 6.2 Tavily 推荐流程

```text
用户选择路书点位
    ↓
用户选择偏好：美食 / 景点 / 住宿 / 补给 / 拍照
    ↓
后端读取后台搜索模板
    ↓
后端读取偏好绑定的网站
    ↓
生成 Tavily 查询请求
    ↓
Tavily 返回搜索结果
    ↓
系统规则评分、去重、过滤
    ↓
AI 生成摘要和推荐理由
    ↓
返回推荐列表
    ↓
用户收藏、忽略或加入路书
```

### 6.3 开始旅游流程

```text
用户手机 H5 打开路书
    ↓
点击开始旅游
    ↓
浏览器请求定位权限
    ↓
获取当前位置
    ↓
后端创建出行实例
    ↓
系统匹配用户当前所在位置
    ↓
判断当前目标点
    ↓
用户点击开始导航
    ↓
系统生成高德 URI
    ↓
浏览器唤醒高德地图 App
    ↓
用户到达目标点
    ↓
回到 H5 页面打卡
    ↓
系统进入下一目标点
```

### 6.4 打卡流程

```text
用户到达点位附近
    ↓
系统提示可以打卡
    ↓
用户点击打卡
    ↓
系统校验当前位置和目标点距离
    ↓
记录打卡经纬度、时间、距离、方式
    ↓
点位状态变为已打卡
    ↓
当前目标切换到下一个未完成点
```

### 6.5 分享流程

```text
用户点击分享
    ↓
系统生成 share_code
    ↓
生成短链
    ↓
访问者打开短链
    ↓
系统根据 share_code 查询指定路书
    ↓
只返回当前路书公开字段
```

### 6.6 邀请流程

```text
路书创建者生成邀请链接
    ↓
设置邀请角色
    ↓
被邀请人打开链接
    ↓
手机号注册或登录
    ↓
接受邀请
    ↓
写入路书成员表
    ↓
获得对应路书权限
```

## 7. 业务模块设计

### 7.1 路书模块

负责路书主数据管理。

功能：

1. 创建路书。
2. 编辑路书基础信息。
3. 查询我的路书。
4. 查询路书详情。
5. 删除路书。
6. 复制路书。
7. 发布路书。
8. 归档路书。

路书状态：

```text
DRAFT       草稿
PUBLISHED   已发布
ARCHIVED    已归档
DELETED     已删除
```

路书可见性：

```text
PRIVATE     仅自己可见
MEMBER      成员可见
SHARE       分享可见
PUBLIC      公开可见，后期可选
```

### 7.2 点位模块

负责路书中的地点管理。

点位类型：

```text
START       起点
END         终点
WAYPOINT    途经点
FOOD        美食
SCENIC      景点
HOTEL       住宿
FUEL        加油
CHARGE      充电
REPAIR      维修
REST        休息
PHOTO       拍照点
CUSTOM      自定义
```

点位来源：

```text
AMAP        高德 POI
MANUAL      用户手动标点
RECOMMEND   Tavily 推荐加入
COPY        复制路书产生
```

### 7.3 地图服务模块

负责封装高德地图相关后端接口。

功能：

1. POI 搜索。
2. POI 详情查询。
3. 地理编码。
4. 逆地理编码。
5. 路径规划。
6. 分段路线计算。
7. 高德 URI 生成。

### 7.4 Tavily 推荐模块

负责旅游推荐搜索。

功能：

1. 根据点位生成搜索关键词。
2. 根据偏好读取搜索站点。
3. 调用 Tavily Search API。
4. 结果去重。
5. 规则评分。
6. AI 摘要。
7. 推荐理由生成。
8. 推荐结果入库。
9. 推荐结果一键加入路书。

### 7.5 出行模块

负责用户实际出游过程。

功能：

1. 开始旅游。
2. 创建出行实例。
3. 当前定位匹配。
4. 当前目标点判断。
5. 分段导航链接生成。
6. 出行进度更新。
7. 结束旅游。

出行状态：

```text
ONGOING     进行中
PAUSED      暂停
FINISHED    已完成
CANCELED    已取消
```

### 7.6 打卡模块

负责用户到点确认。

点位进度状态：

```text
NOT_STARTED    未开始
CURRENT        当前目标
ARRIVED        已到达附近
CHECKED_IN     已打卡
SKIPPED        已跳过
MISSED         疑似错过
```

打卡方式：

```text
GPS_CHECKIN       定位范围内打卡
MANUAL_CHECKIN    手动打卡
ADMIN_CHECKIN     后台修正
```

### 7.7 分享模块

负责短链分享。

功能：

1. 生成分享短链。
2. 设置过期时间。
3. 设置访问密码。
4. 限制访问当前路书。
5. 统计访问次数。
6. 禁用分享链接。

### 7.8 邀请协作模块

负责路书协作权限。

成员角色：

```text
OWNER       所有者
MANAGER     管理员
EDITOR      编辑者
COMMENTER   评论者
VIEWER      查看者
```

### 7.9 后台配置模块

后台配置内容：

1. 高德地图配置。
2. Tavily API 配置。
3. AI 模型配置。
4. 偏好标签配置。
5. 搜索站点配置。
6. 偏好站点绑定。
7. 搜索模板配置。
8. 打卡半径配置。
9. 导航策略配置。

### 7.10 审计日志模块

记录关键操作：

1. 创建路书。
2. 修改路书。
3. 删除路书。
4. 添加点位。


## 10. 当前定位匹配算法

### 10.1 输入

```text
routebookId
journeyId
userId
lng
lat
accuracy
```

### 10.2 输出

```text
当前目标点
是否可打卡
匹配类型
距离
提示文案
```

### 10.3 匹配优先级

第一优先级：用户在当前目标点打卡半径内。

```text
返回 ARRIVED_TARGET
允许打卡
```

第二优先级：用户在某个未完成点位打卡半径内。

```text
返回 ARRIVED_UNFINISHED_POINT
提示是否将该点设为当前目标并打卡
```

第三优先级：用户靠近某段路线。

```text
返回 ON_SEGMENT
目标点取该段终点
```

第四优先级：用户距离某个未完成点最近。

```text
返回 NEAREST_UNFINISHED_POINT
目标点取最近未完成点
```

第五优先级：无法匹配。

```text
返回 UNKNOWN
提示用户手动选择当前目标
```

```text

4. 分享链接的只读访问权限
```

### 12.3 分享权限原则

分享链接只能访问当前分享的路书。分享接口不能使用真实 `routebookId` 直接查询，必须通过 `shareCode` 查询并限制字段输出。

## 13. 安全设计

1. 所有第三方 Key 存储时建议加密。
2. 分享链接使用随机短码，不能使用递增 ID。
3. 邀请链接需要有效期和使用次数限制。
4. 手机定位数据只在用户主动开始旅游后记录。
5. 定位日志定期清理。
6. Tavily 和 AI 调用需要记录日志和调用消耗。
7. 后台配置修改需要记录审计日志。
8. 分享页不返回用户手机号、后台字段、内部权限字段。
9. 打卡支持手动操作，但需要记录手动打卡原因。
10. 远距离手动打卡可以允许，但必须留下距离、原因和时间。
