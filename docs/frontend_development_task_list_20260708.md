# 智能路书前端开发任务清单

生成日期：2026-07-08

## 0. 最高优先级：全局后台风格重设计

1. 产出全局后台 UI / UX 重设计文档，覆盖布局、配色、字体、组件、页面模板、暗色模式、响应式和后续新增页面约束。
2. 建立可复用的全局样式变量、业务页面容器、列表页模板、详情页模板、表单页模板和空状态规范。
3. 将现有若依后台模板风格逐步替换为“智能路书工作台”风格，避免后续新页面继续复制旧模板视觉。
4. 明确新增页面必须遵守的设计检查项，保证后续接入路书、地图、推荐、出行、后台配置等模块时风格一致。
5. 优先处理全局布局、登录页、首页、侧边栏、顶部导航、列表页基础样式，再推进业务页面开发。

## 1. 基础清理与项目入口

1. 清理若依模板残留文案、默认首页、登录页、外链入口。
2. 固定系统名称、浏览器标题、侧边栏标题为“智能路书工作台”。
3. 保留若依 Token、权限码、分页参数、返回结构兼容。

## 2. 前端 API 分层

1. 新建 `src/api/trip/routebook.ts`：路书、模板、GPX/KML 导出。
2. 新建 `src/api/trip/point.ts`：点位、排序、每日行程、评论。
3. 新建 `src/api/trip/segment.ts`：分段路线、重算。
4. 新建 `src/api/trip/map.ts`：POI、路线规划、高德 URI。
5. 新建 `src/api/trip/recommend.ts`：Tavily 推荐、AI 摘要、加入路书。
6. 新建 `src/api/trip/share.ts`：分享短链。
7. 新建 `src/api/trip/invite.ts`：邀请协作。
8. 新建 `src/api/trip/journey.ts`：H5 出行。
9. 新建 `src/api/trip/admin.ts`：后台配置与日志。

## 3. PC 路书地图工作台

1. 路书分页、详情、新建、编辑、删除。
2. 路书复制、发布、归档。
3. 路书模板列表、设为模板、取消模板、从模板创建。
4. GPX / KML 导出。
5. 地图展示点位和分段路线。
6. POI 搜索、POI 详情、地图选点加入路书。

## 4. 点位与每日行程

1. 点位列表、新增、编辑、删除。
2. 点位拖拽排序。
3. 批量设置点位所属天数。
4. 分段路线列表展示。
5. 触发分段路线重新计算。
6. 点位评论列表、新增、编辑、删除。

## 5. 推荐与 AI

1. 推荐搜索。
2. 推荐结果分页列表。
3. AI 摘要、推荐理由、风险提醒重生成。
4. 推荐结果加入路书点位。
5. 天气与风险提醒接口接入。
6. 处理无 Key 降级、有 Key 正常调用两种状态。

## 6. 分享与邀请

1. 创建分享链接、分享列表、禁用分享。
2. 公开分享页 `/s/{shareCode}`。
3. 支持分享访问密码交互，具体方式待确认。
4. 创建邀请链接、邀请列表、禁用邀请。
5. 公开邀请页 `/invite/{inviteCode}`。
6. 登录后接受邀请并写入路书成员。

## 7. H5 出行页

1. 分享路书详情查看。
2. 开始出行。
3. 出行详情：当前目标点、已打卡点、待打卡点。
4. 定位匹配当前目标点。
5. 唤起高德地图分段导航。
6. GPS / 手动打卡。
7. 跳过点位、撤销打卡、调整当前目标点。
8. 结束出行、取消出行。

## 8. 后台配置

1. 推荐偏好 CRUD、启停、启用列表。
2. 搜索站点 CRUD、启停、启用列表。
3. 偏好站点绑定 CRUD、启停、按偏好查询启用绑定。
4. Tavily 搜索模板 CRUD、启停、按偏好查询启用模板。

## 9. 后台日志

1. 审计日志分页、详情。
2. 第三方调用日志分页、详情。
3. 核对高德、Tavily、AI 调用日志链路。

## 10. 权限与联调

1. 按权限码控制按钮显示。
2. 核对普通角色 `role_id=2` 是否用于联调。
3. 初始化权限脚本后验证 `3000-3199` 菜单权限。
4. 确认路书成员角色在前端的按钮隐藏策略。

## 11. 回归验证

1. 登录后验证 `/trip/screen/routebooks/page`。
2. 路书、点位、分段路线、推荐、分享、邀请、出行全主链路回归。
3. GPX / KML 下载验证响应头和 XML 内容。
4. 后台配置与日志接口回归。
5. 后端 Maven 编译和接口回归由具备 Maven 的环境执行。

## 12. 待确认事项

1. PC 大屏工作台路由与页面命名。
2. H5 页面是否复用当前前端工程，还是拆分单独 H5 工程。
3. 分享页访问密码交互方式。
4. 路书成员角色权限在前端的按钮隐藏策略。
5. 普通角色账号是否参与完整联调。
