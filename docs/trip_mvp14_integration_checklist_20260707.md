## 2. 配置核对

1. 高德 Web 服务 Key：`trip.amap.web-service-key`。
2. 高德 URI 调起配置：`trip.amap.uri-scheme`、`trip.amap.uri-package`。
3. Tavily 搜索 Key：推荐搜索联调前确认已配置。
4. DeepSeek / AI 配置：推荐 AI 摘要和风险理由联调前确认已配置。
5. 普通角色 `role_id=2` 是否允许用于联调；权限脚本会默认追加 `3000-3199` 菜单。

## 3. 接口主链路

1. 登录后访问 `/trip/screen/routebooks/page`，确认路书分页可用。
2. 新建路书、编辑路书、复制路书、发布路书、归档路书。
3. 对路书点位执行新增、编辑、排序、每日行程拆分、删除。
4. 调用 POI 搜索、POI 详情、路线规划、路线重算、导航 URI。
5. 创建分享链接，访问公开分享详情并确认访问次数递增。
6. 创建邀请链接，公开查看邀请，登录后接受邀请并写入成员。
7. 开始出行，执行定位匹配、打卡、跳过点位、撤销打卡、调整当前目标、结束出行。
8. 执行推荐搜索，查看推荐列表，触发 AI 生成，将推荐加入路书。
9. 导出 GPX / KML，确认响应头为附件下载且 XML 内容可被地图工具识别。
10. 设置路书模板、取消模板、从模板创建路书。
11. 对点位新增、修改、删除评论。
12. 调用 `/trip/screen/risk/reminders`，确认无 Key 降级、有 Key 时天气提醒与调用日志正常。

## 4. 后台核对

1. 访问 `/trip/admin/audit-logs/page` 和详情，确认业务操作审计记录可查询。
2. 访问 `/trip/admin/call-logs/page` 和详情，确认高德、Tavily、AI 调用日志可查询。
3. 使用权限脚本初始化后的普通角色账号逐项访问接口，确认不存在缺失权限码导致的误拦截。

## 5. 已知限制

1. 本阶段未覆盖 PC / H5 前端页面实现，前端联调需按接口逐步接入。
2. 天气提醒当前只接入高德实时天气，尚未接入天气预报、实时路况和补给点自动识别。
3. 点位评论暂不支持楼中楼、附件和按成员角色细分权限。
4. 路书成员权限校验尚未统一接入所有路书操作接口。
5. 需要在具备 Maven 的环境执行后端编译、启动和接口回归。
